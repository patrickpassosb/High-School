# JogoDB SQL Game Database

This SQL project simulates an online RPG game database. It includes:

- Tables for `Jogador`, `Personagem`, `Missao`, and `Inventario`
- Stored procedures (e.g., `RegistrarMissao`, `SubirNivelPersonagem`)
- Views and indexes for performance
- Backup and restore scripts
- Read-only user security setup

## How to Use

1. Open in SQL Server Management Studio or Azure Data Studio
2. Run each script step by step
3. Explore characters, experience points, and BTC mechanics!
