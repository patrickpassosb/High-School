# DuinoBot

---

DuinoBot is a simple chatbot assistant built with Python. It integrates a powerful AI language model (Groq's LLaMA 3 70B Versatile model) via the LangChain library to hold friendly conversations. This project was developed as a high school project aiming for top marks, demonstrating how an advanced AI model can be used in a beginner-friendly chat application. DuinoBot (the bot's name is Duino) can answer questions and chat with you just like a helpful assistant.

---

# Project Description

DuinoBot is designed to be easy to use, even if you're new to programming or AI:

  **Chatbot Assistant:** You can ask DuinoBot questions or have a casual conversation. It will respond in a helpful and friendly manner.

  **Powered by LLaMA 70B:** Behind the scenes, DuinoBot uses the LLaMA 3 70B Versatile large language model (which has 70 billion parameters, making it very powerful). This model is provided through Groq, a platform that hosts advanced AI models.

  **LangChain Integration:** The project uses the LangChain library to connect our chatbot code with the Groq AI model easily. You don't need to deeply understand LangChain to use DuinoBot – just know that it helps manage the conversation with the AI.

In simple terms: DuinoBot is a Python program that sends your messages to a big AI model on Groq's servers and gives you the model's answer. The result is a conversational assistant that you can talk to
